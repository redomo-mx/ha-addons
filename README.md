# Complementos de Home Assistant de Redomo

Este repositorio contiene los complementos que Redomo instala en el centro de
control de cada casa.

## Instalación

En Home Assistant:

1. **Ajustes → Complementos → Tienda de complementos**
2. Menú de los tres puntos, arriba a la derecha → **Repositorios**
3. Añadir: `https://github.com/redomo-mx/ha-addons`
4. Cerrar y buscar **Agente Redomo** en la tienda

## Complementos

| Complemento | Qué hace |
|---|---|
| [Agente Redomo](redomo-agent/) | Ejecuta las automatizaciones de la casa de forma continua, sin depender de que la app esté abierta |
